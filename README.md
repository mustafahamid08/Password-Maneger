🔐 Password Manager

A simple Python-based Password Manager that helps users store, manage, search, and generate passwords.

✨ Features

- Add and save passwords
- View saved passwords
- Search passwords by website
- Generate strong random passwords
- Delete saved passwords
- Store password data locally in a CSV file
- Simple and easy-to-use command-line interface

🛠️ Technologies Used

- Python
- CSV
- Random
- String

📌 Project Purpose

This project was created to practice Python programming concepts such as functions, file handling, loops, conditional statements, modules, and data management.
